# رحلة البكالوريا 🎓
## Baccalaureate Journey - Free Educational Platform

منصة تعليمية مجانية وتفاعلية لطلاب البكالوريا، توفر دروساً وامتحانات حسب المسار الدراسي.

### الميزات الرئيسية ✨

#### للطلاب 👨‍🎓
- ✅ إنشاء حساب شخصي وتسجيل دخول آمن
- 📚 الوصول إلى مواد مخصصة حسب مسارك الدراسي
- 🎥 مشاهدة دروس فيديو من YouTube
- 📝 إجراء امتحانات تفاعلية مع تصحيح فوري
- 📊 متابعة التقدم ومتوسط الدرجات

#### للمسؤولين ⚙️
- 🛠️ إدارة المواد والدروس
- 🎬 إضافة فيديوهات تعليمية
- 📋 إنشاء امتحانات تفاعلية
- 👥 مراقبة حسابات الطلاب ودرجاتهم
- 💾 تصدير واستيراد البيانات

### المسارات المدعومة 🎯

1. **الطب وعلوم الحياة** - عربي، إنجليزي، تاريخ، فيزياء، رياضيات
2. **الهندسة وعلوم الحاسب** - عربي، إنجليزي، تاريخ، كيمياء، برمجة
3. **الأعمال** - عربي، إنجليزي، تاريخ، محاسبة، إدارة الأعمال
4. **الآداب والفنون** - عربي، إنجليزي، تاريخ، علم النفس، فرنساوي

### كيفية الاستخدام 🚀

#### للطلاب:
1. افتح الموقع
2. اختر **"إنشاء حساب"**
3. أدخل بياناتك واختر مسارك
4. ابدأ بالمذاكرة! 📖

#### للأدمن:
1. اضغط على اسم المنصة "رحلة البكالوريا"
2. أدخل كلمة المرور: **7384**
3. أدر المحتوى والامتحانات

### التقنيات المستخدمة 💻
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Storage**: LocalStorage (لا يتطلب خادم)
- **Responsive**: متوافق مع جميع الأجهزة
